Implementation of a session-less authentication flow featuring asynchronous AJAX registration, token-based verification via localStorage, and dynamic profile retrieval.

Technical Overview
  • Flow: Register → Login → Profile
  • Frontend: Bootstrap 5, jQuery AJAX, localStorage session management
  • Backend & Storage: PHP endpoints, MySQL (Prepared Statements), MongoDB, and Redis
